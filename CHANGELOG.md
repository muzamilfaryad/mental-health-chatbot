# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-18

### Added
- Initial release of Mental Health Chatbot
- Gradio web interface for chat interactions
- Integration with Hugging Face Qwen 2.5-72B-Instruct model
- Customizable conversation parameters (temperature, max tokens, top-p)
- Environment-based configuration with .env support
- Streaming response generation
- Conversation history management
- Windows quick-start batch script (run.bat)
- Comprehensive documentation (README, CONTRIBUTING, LICENSE)
- Mental Health FAQ dataset

### Features
- Real-time AI-powered mental health support
- Adjustable system prompts
- Clean and intuitive user interface
- Secure API token management
- Cross-platform compatibility (Windows, macOS, Linux)

### Security
- API tokens stored securely in .env file
- .gitignore configured to prevent token exposure
- No conversation data stored locally
