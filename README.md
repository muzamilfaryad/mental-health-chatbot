## 🚀 Quick Start

<div align="center">

### Get up and running in 3 easy steps!

</div>

### 📋 Prerequisites

```bash
✅ Python 3.7 or higher
✅ pip (Python package manager)
✅ Hugging Face account (free)
```

### 🔧 Installation

<details open>
<summary><b>🪟 Windows Installation</b></summary>

```bash
# 1. Clone the repository
git clone https://github.com/muzamilfaryad/mental-health-chatbot.git
cd mental-health-chatbot

# 2. Create virtual environment
python -m venv venv
venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set up your token
copy .env.example .env
# Edit .env and add your Hugging Face token

# 5. Run the app
python app.py

# OR just double-click run.bat! 🎉
```

</details>

<details>
<summary><b>🍎 macOS Installation</b></summary>

```bash
# 1. Clone the repository
git clone https://github.com/muzamilfaryad/mental-health-chatbot.git
cd mental-health-chatbot

# 2. Create virtual environment
python3 -m venv venv
source venv/bin/activate

# 3. Install dependencies
pip3 install -r requirements.txt

# 4. Set up your token
cp .env.example .env
# Edit .env and add your Hugging Face token

# 5. Run the app
python3 app.py
```

</details>

<details>
<summary><b>🐧 Linux Installation</b></summary>

```bash
# 1. Clone the repository
git clone https://github.com/muzamilfaryad/mental-health-chatbot.git
cd mental-health-chatbot

# 2. Create virtual environment
python3 -m venv venv
source venv/bin/activate

# 3. Install dependencies

# 4. Set up your token
cp .env.example .env
nano .env  # Add your Hugging Face token

# 5. Run the app
python3 app.py
```

</details>

<br/>

### 🔑 Getting Your Hugging Face Token

1. 🌐 Visit [Hugging Face](https://huggingface.co/join) and create a free account
2. 🔑 Go to [Settings → Access Tokens](https://huggingface.co/settings/tokens)
3. ➕ Click **"New token"**
4. ✍️ Name it (e.g., "Mental Health Chatbot")
5. ✅ Select **"Read"** permission
6. 📋 Copy your token
7. 📝 Paste it in your `.env` file:
   ```env
   HF_TOKEN=hf_your_actual_token_here
   ```

<br/>

### 🎉 Launch

```bash
python app.py
```

Then open your browser to: **http://127.0.0.1:7860** 🌐

## 🎨 Customization Options

<div align="center">

### Tailor the chatbot to your preferences

</div>

| Setting | Purpose | Default | Range | Effect |
|---------|---------|---------|-------|--------|
| **System Message** | Define bot personality | Friendly & Empathetic | Custom text | Changes tone and behavior |
| **Temperature** | Response creativity | `0.7` | `0.1` - `4.0` | Lower = focused, Higher = creative |
| **Max Tokens** | Response length | `512` | `1` - `2048` | Longer = detailed responses |
| **Top-p** | Response diversity | `0.95` | `0.1` - `1.0` | Controls answer variety |

<br/>

**💡 Tip:** Start with defaults and experiment to find your perfect balance!

## 🐛 Troubleshooting

<details>
<summary><b>❌ Common Issues & Solutions</b></summary>

<br/>

**Problem:** `ModuleNotFoundError: No module named 'gradio'`
```bash
Solution: pip install -r requirements.txt
```

**Problem:** API Authentication Error
```bash
Solution: 
1. Check your HF_TOKEN in .env file
2. Ensure no extra spaces or quotes
3. Verify token has "Read" permission
4. Regenerate token if necessary
```

**Problem:** Port 7860 already in use
```python
# Solution: Change port in app.py
demo.launch(server_port=7861)
```

**Problem:** Slow responses
```bash
Solutions:
- Check internet connection
- Reduce max_tokens to 256
- Lower temperature to 0.5
- Try during off-peak hours
```

**Problem:** Module version conflicts
```bash
Solution: 
pip install --upgrade -r requirements.txt
```

</details>
